🔥 Conectar Firebase — Base de Datos en la Nube GRATIS

Si conecta Firebase, todos los que usen el link verán la misma información en tiempo real. Sin Firebase, cada computadora guarda sus propios datos.

  1. Vaya a https://firebase.google.com e inicie sesión con Google
  2. Cree un proyecto → Firestore Database → "Modo de prueba"
  3. En Configuración del proyecto (⚙️) → "Sus aplicaciones" → ícono Web </>
  4. Copie el bloque firebaseConfig = { ... } y péguelo aquí:

📤 Cómo publicar en Netlify (GRATIS)
  1. Descargue este archivo HTML (botón abajo)
  2. Vaya a https://netlify.com → regístrese gratis
  3. Arrastre y suelte el archivo HTML en el dashboard de Netlify
  4. Netlify le dará un link como: https://medistock-clinica.netlify.app
  5. Comparta ese link con todo su equipo — funciona en celular y computadora
